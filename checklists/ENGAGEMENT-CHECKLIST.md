# Pre-Test Authorization Checklist

- [ ] Written authorization received
- [ ] System owner and emergency contact recorded
- [ ] Exact domains, IPs, endpoints, and versions documented
- [ ] Test window and request-rate limits agreed
- [ ] Allowed and prohibited techniques documented
- [ ] Synthetic test accounts and records prepared
- [ ] Backup/rollback and stop conditions agreed
- [ ] Evidence storage and retention rules agreed
- [ ] Secret and personal-data redaction process ready
- [ ] Retest approval process defined
